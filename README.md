# ربات پاسخ‌گوی خودکار قیمت - واتساپ میوه‌فروشی

این ربات پیام‌های واتساپ رو می‌خونه، اگه اسم یکی از محصولات (مثل "رطب"، "خیار"، "پیاز") توش باشه، خودکار قیمت روزش رو جواب می‌ده.

## مرحله ۱: ساخت اکانت Green API (رایگان برای شروع)

1. برو به سایت green-api.com و ثبت‌نام کن.
2. یک Instance جدید بساز.
3. با اسکن QR کد (دقیقاً مثل واتساپ وب)، شماره واتساپ بیزینس شرکت رو بهش وصل کن.
4. از پنل، دو مقدار `idInstance` و `apiTokenInstance` رو کپی کن.

## مرحله ۲: آپلود کد روی یک سرویس رایگان (پیشنهاد: Render.com)

1. یک اکانت رایگان در render.com بساز (میشه با گیت‌هاب واردش شد).
2. توی Render، گزینه "New Web Service" رو بزن و ریپازیتوری گیت‌هاب رو انتخاب کن.
3. تنظیمات:
   - Build Command: `npm install`
   - Start Command: `npm start`
4. توی بخش Environment Variables این دو مقدار رو وارد کن:
   - `GREEN_API_ID_INSTANCE` = همون idInstance
   - `GREEN_API_TOKEN` = همون apiTokenInstance
5. Deploy کن.

## مرحله ۳: وصل کردن Webhook

1. برگرد به پنل Green API.
2. توی تنظیمات Instance، فیلد "Webhook URL" رو پیدا کن.
3. آدرس Render رو بذار توش، به همراه `/webhook` در انتها.
4. گزینه "Incoming messages" رو فعال کن و ذخیره کن.

## چطور قیمت‌ها رو آپدیت کنم؟

فایل `prices.js` رو توی گیت‌هاب باز کن، عدد جلوی هر محصول رو عوض کن و Commit کن.

## اضافه کردن محصول جدید

توی `prices.js` یک بلوک جدید مثل بقیه اضافه کن.
